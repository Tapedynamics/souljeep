# 🚗 SOUL JEEP EXPERIENCE - Website

Premium Jeep Wrangler tours in Tenerife - Modern Next.js website

---

## 🚀 Quick Start

```bash
cd website
npm install
npm run dev
```

**Dev Server**: http://localhost:3002

## 🛠 Stack Tecnologico

- **Framework**: Next.js 15.0.3
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Fonts**: Google Fonts (Inter + Poppins)
- **Image Optimization**: Next.js Image
